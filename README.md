This project controls the moving walls, doors and ceiling planes of an architectural model with four MG90S micro servos. An Elegoo Uno R3 (Arduino) drives the servos through a PCA9685 servo driver board, powered by an Anker 737 power bank hidden in the base. A custom browser dashboard connects to the Arduino over USB for live control of each servo's angle and speed. It saves "Open" and "Close" poses to the Arduino, so two physical push buttons run the model without a computer. An optional sequential mode moves the panels one after another, with adjustable timing. (Check out the Fruitier Aero UI setting, angry mode in the bottom right)
